# Coding Distillation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Distill Python coding behavior from Opus 5.5 into `Qwen/Qwen2.5-Coder-0.5B-Instruct` via LoRA SFT and measure HumanEval pass@1 before and after.

**Architecture:** A standalone `uv` project in `projects/coding-distillation/`. A small library package `distill` (sandbox execution, chat formatting/code extraction, contamination check, validation, evaluation helpers, model loading) is unit-tested with pytest; thin numbered scripts in `scripts/` drive each pipeline step. Teacher data is written in-session by Opus subagents as raw JSONL, then filtered by execution and contamination checks.

**Tech Stack:** Python 3.12, uv, torch (MPS), transformers, datasets, peft, trl, accelerate, pytest.

**Spec:** `coding-distillation-design.md` (repo root)

## Global Constraints

- Project root: `projects/coding-distillation/`; all commands below run from that directory.
- Student model: `Qwen/Qwen2.5-Coder-0.5B-Instruct`. Benchmark: `openai/openai_humaneval`, split `test`, 164 problems.
- Same `SYSTEM_PROMPT` and `USER_TEMPLATE` (from `distill.format`) for training data and evaluation.
- Evaluation: greedy decoding, `max_new_tokens=512`, sandbox timeout 5.0 s, pass@1 = passed / total.
- LoRA: r=16, alpha=32, dropout=0.05, `target_modules="all-linear"`. SFT: lr 2e-4, 3 epochs, per-device batch 4 × grad-accum 4 (effective 16), max length 1024, loss on assistant tokens only, seed 42.
- Validation: ≥3 asserts per record; contamination reject if word-5-gram Jaccard ≥ 0.3 vs any HumanEval prompt or entry-point name equals a HumanEval entry point; 90/10 train/val split with seed 42.
- Model dtype: float32 on all devices (deviation from spec's "bf16 with fp32 fallback": a 0.5B model in fp32 is ~2 GB, and fp32 avoids MPS bf16/mixed-precision issues; base and fine-tuned use the same dtype, so the comparison is unaffected).
- `outputs/` and `.venv/` are gitignored. Teacher data and weights are not published.
- Work happens on branch `coding-distillation`, not `main`.

## Review Focus

1. Model code that calls `exit()` / `sys.exit(0)` at top level before tests run → must count as **fail**, not pass (sandbox requires a sentinel printed after the program). Test in Task 1.
2. Model code that calls `input()` → must fail fast, not hang until timeout or block forever (stdin is `/dev/null`). Test in Task 1.
3. Generation truncated at `max_new_tokens` with an unclosed ```` ```python ```` fence → code is still extracted from the open block. Test in Task 2.
4. HumanEval prompts containing imports or helper functions (e.g. `from typing import List`, `encode_cyclic` above `decode_cyclic`) where the model returns only its function → prompt is prepended so names resolve; model's definition overrides the stub. Test in Task 2.
5. Eval interrupted mid-write leaves a partial last JSONL line → resume ignores it and re-runs that task instead of crashing. Test in Task 6.

```python
"""Run untrusted-ish Python in a subprocess. Not a security boundary."""
import subprocess
import sys
import tempfile
from dataclasses import dataclass
from pathlib import Path

SENTINEL = "__DISTILL_DONE__"


@dataclass(frozen=True)
class Result:
    passed: bool
    error: str


def run(code: str, timeout: float = 5.0) -> Result:
    # The sentinel is printed only if execution reaches the end of the program,
    # so an early exit(0) is not mistaken for passing tests.
    program = f"{code}\n\nprint({SENTINEL!r})\n"
    with tempfile.TemporaryDirectory() as tmp:
        path = Path(tmp) / "prog.py"
        path.write_text(program)
        try:
            proc = subprocess.run(
                [sys.executable, "-I", str(path)],
                cwd=tmp,
                stdin=subprocess.DEVNULL,
                capture_output=True,
                text=True,
                timeout=timeout,
            )
        except subprocess.TimeoutExpired:
            return Result(False, "timeout")
    passed = proc.returncode == 0 and proc.stdout.rstrip().endswith(SENTINEL)
    return Result(passed, "" if passed else proc.stderr[-2000:])
```

```python
"""Shared chat template for training and evaluation, plus code extraction."""
import re

SYSTEM_PROMPT = (
    "You are an expert Python programmer. Briefly explain your approach, "
    "then give the complete function in a single ```python code block."
)
USER_TEMPLATE = "Complete the following Python function:\n```python\n{prompt}```"

_CLOSED = re.compile(r"```(?:python|py)?[ \t]*\n(.*?)```", re.S)
_OPEN_TAIL = re.compile(r"```(?:python|py)?[ \t]*\n((?:(?!```).)*)$", re.S)


def _with_newline(s: str) -> str:
    return s if s.endswith("\n") else s + "\n"


def to_messages(prompt, solution=None, explanation=None):
    msgs = [
        {"role": "system", "content": SYSTEM_PROMPT},
        {"role": "user", "content": USER_TEMPLATE.format(prompt=_with_newline(prompt))},
    ]
    if solution is not None:
        body = f"{explanation.strip()}\n" if explanation else ""
        msgs.append({
            "role": "assistant",
            "content": f"{body}```python\n{solution.rstrip()}\n```",
        })
    return msgs


def extract_code(text, prompt, entry_point):
    blocks = _CLOSED.findall(text)
    # An odd number of fences means generation stopped inside a block.
    if text.count("```") % 2 and (tail := _OPEN_TAIL.search(text)):
        blocks.append(tail.group(1))
    defining = [b for b in blocks if f"def {entry_point}" in b]
    if defining:
        code = defining[-1]
    elif blocks:
        code = blocks[0]
    else:
        code = text
    code = _with_newline(code)
    # The prompt supplies imports and helper functions; a full definition from
    # the model follows it and overrides the docstring-only stub.
    if f"def {entry_point}" in code:
        return _with_newline(prompt) + "\n" + code
    return _with_newline(prompt) + code
```

```python
"""Keep generated training problems from overlapping with HumanEval."""
import re


def load_humaneval():
    from datasets import load_dataset

    return list(load_dataset("openai/openai_humaneval", split="test"))


def ngrams(text, n=5):
    tokens = re.findall(r"[a-z0-9]+", text.lower())
    return {tuple(tokens[i:i + n]) for i in range(len(tokens) - n + 1)}


def jaccard(a, b):
    if not a and not b:
        return 0.0
    return len(a & b) / len(a | b)


def check(prompt, entry_point, he_prompts, he_entry_points, threshold=0.3):
    if entry_point in he_entry_points:
        return "contamination_name"
    grams = ngrams(prompt)
    if any(jaccard(grams, ngrams(p)) >= threshold for p in he_prompts):
        return "contamination_ngram"
    return None
```

```python
"""Load the student model (optionally with a LoRA adapter) and generate greedily."""
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer

MODEL_ID = "Qwen/Qwen2.5-Coder-0.5B-Instruct"


def pick_device(name=None):
    if name:
        return name
    return "mps" if torch.backends.mps.is_available() else "cpu"


def load_model(device, adapter=None):
    tokenizer = AutoTokenizer.from_pretrained(MODEL_ID)
    model = AutoModelForCausalLM.from_pretrained(MODEL_ID, dtype=torch.float32)
    if adapter:
        from peft import PeftModel

        model = PeftModel.from_pretrained(model, adapter).merge_and_unload()
    return model.to(device).eval(), tokenizer


@torch.no_grad()
def generate(model, tokenizer, messages, max_new_tokens=512):
    inputs = tokenizer.apply_chat_template(
        messages, add_generation_prompt=True, return_dict=True, return_tensors="pt"
    ).to(model.device)
    out = model.generate(
        **inputs,
        max_new_tokens=max_new_tokens,
        do_sample=False,
        pad_token_id=tokenizer.eos_token_id,
    )
    return tokenizer.decode(out[0, inputs["input_ids"].shape[1]:], skip_special_tokens=True)
```

```python
"""Filter raw teacher records: schema, contamination, dedupe, execution."""
import json
import random
import re

from distill.contamination import check
from distill.sandbox import run

REQUIRED = ("id", "topic", "difficulty", "prompt", "solution", "explanation", "tests", "entry_point")


def _schema_error(r):
    missing = [k for k in REQUIRED if not isinstance(r.get(k), str) or not r[k].strip()]
    if missing:
        return f"missing/empty: {missing}"
    if r["tests"].count("assert") < 3:
        return "fewer than 3 asserts"
    defn = f"def {r['entry_point']}"
    if defn not in r["prompt"] or defn not in r["solution"]:
        return f"{defn} not in prompt and solution"
    return None


def _normalize(prompt):
    return re.sub(r"\s+", " ", prompt).strip().lower()


def validate_records(lines, he_prompts, he_entry_points):
    accepted, rejected, seen = [], [], set()

    def reject(r, reason, detail=""):
        rejected.append({"id": r.get("id") if isinstance(r, dict) else None, "reason": reason, "detail": detail})

    for line in lines:
        if not line.strip():
            continue
        try:
            r = json.loads(line)
        except json.JSONDecodeError as e:
            reject(None, "parse_error", str(e))
            continue
        if not isinstance(r, dict):
            reject(None, "parse_error", "not an object")
            continue
        if err := _schema_error(r):
            reject(r, "schema", err)
            continue
        if reason := check(r["prompt"], r["entry_point"], he_prompts, he_entry_points):
            reject(r, reason)
            continue
        key = _normalize(r["prompt"])
        if key in seen:
            reject(r, "duplicate")
            continue
        result = run(r["solution"] + "\n\n" + r["tests"])
        if not result.passed:
            reject(r, "tests_failed", result.error)
            continue
        seen.add(key)
        accepted.append(r)
    return accepted, rejected


def split(records, val_frac=0.1, seed=42):
    shuffled = list(records)
    random.Random(seed).shuffle(shuffled)
    n_val = max(1, round(len(shuffled) * val_frac))
    return shuffled[n_val:], shuffled[:n_val]
```

```python
"""HumanEval scoring helpers and before/after report."""
import json


def build_program(code, test, entry_point):
    return f"{code}\n\n{test}\n\ncheck({entry_point})\n"


def load_done(path):
    done = {}
    if not path.exists():
        return done
    for line in path.read_text().splitlines():
        try:
            rec = json.loads(line)
        except json.JSONDecodeError:
            continue
        done[rec["task_id"]] = rec
    return done


def pass_at_1(records):
    records = list(records)
    return sum(r["passed"] for r in records) / len(records) if records else 0.0


def _row(name, recs):
    n = sum(r["passed"] for r in recs.values())
    return f"| {name} | {n}/{len(recs)} | {100 * pass_at_1(recs.values()):.1f}% |"


def compare(base, ft, n_samples=3):
    common = sorted(base.keys() & ft.keys())
    fixed = [t for t in common if ft[t]["passed"] and not base[t]["passed"]]
    broken = [t for t in common if base[t]["passed"] and not ft[t]["passed"]]
    lines = [
        "# HumanEval results: Qwen2.5-Coder-0.5B-Instruct, base vs. distilled LoRA",
        "",
        "Greedy decoding, max 512 new tokens, pass@1.",
        "",
        "| model | passed | pass@1 |",
        "|---|---|---|",
        _row("base", base),
        _row("fine-tuned", ft),
        "",
        f"Fixed by fine-tuning ({len(fixed)}): {', '.join(fixed) or 'none'}",
        "",
        f"Broken by fine-tuning ({len(broken)}): {', '.join(broken) or 'none'}",
        "",
    ]
    for t in fixed[:n_samples]:
        lines += [
            f"## {t}",
            "",
            "**Base (failed):**",
            "```python", base[t]["code"].rstrip(), "```",
            "",
            "**Fine-tuned (passed):**",
            "```python", ft[t]["code"].rstrip(), "```",
            "",
        ]
    return "\n".join(lines)
```

"""HumanEval pass@1 for the base model or base + LoRA adapter; --compare writes results.md."""
import argparse
import json
from pathlib import Path

from distill.contamination import load_humaneval
from distill.evaluate import build_program, compare, load_done, pass_at_1
from distill.format import extract_code, to_messages
from distill.modeling import generate, load_model, pick_device
from distill.sandbox import run

OUT = Path("outputs")


def evaluate(adapter, out_path, limit, device):
    problems = load_humaneval()
    if limit:
        problems = problems[:limit]
    done = load_done(out_path)
    todo = [p for p in problems if p["task_id"] not in done]
    print(f"{len(done)} done, {len(todo)} to go -> {out_path}")
    if todo:
        model, tokenizer = load_model(pick_device(device), adapter)
    with open(out_path, "a") as f:
        for i, p in enumerate(todo, 1):
            completion = generate(model, tokenizer, to_messages(p["prompt"]))
            code = extract_code(completion, p["prompt"], p["entry_point"])
            result = run(build_program(code, p["test"], p["entry_point"]))
            rec = {"task_id": p["task_id"], "completion": completion, "code": code,
                   "passed": result.passed, "error": result.error}
            f.write(json.dumps(rec) + "\n")
            f.flush()
            done[p["task_id"]] = rec
            print(f"[{i}/{len(todo)}] {p['task_id']}: {'PASS' if result.passed else 'FAIL'}")
    scored = [done[p["task_id"]] for p in problems]
    print(f"pass@1 = {pass_at_1(scored):.3f} ({sum(r['passed'] for r in scored)}/{len(scored)})")


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--adapter", help="path to LoRA adapter; omit for base model")
    ap.add_argument("--out", help="output jsonl (default outputs/eval_base.jsonl or eval_ft.jsonl)")
    ap.add_argument("--limit", type=int, help="only the first N problems (smoke test)")
    ap.add_argument("--device", help="mps or cpu (default: auto)")
    ap.add_argument("--compare", action="store_true", help="write results.md from eval_base/eval_ft")
    args = ap.parse_args()

    OUT.mkdir(exist_ok=True)
    if args.compare:
        md = compare(load_done(OUT / "eval_base.jsonl"), load_done(OUT / "eval_ft.jsonl"))
        Path("results.md").write_text(md)
        print(md)
        return
    default = OUT / ("eval_ft.jsonl" if args.adapter else "eval_base.jsonl")
    evaluate(args.adapter, Path(args.out) if args.out else default, args.limit, args.device)


if __name__ == "__main__":
    main()
```

"""LoRA SFT of the student on teacher data -> outputs/lora-adapter/"""
import argparse

import torch
from datasets import load_dataset
from peft import LoraConfig
from transformers import AutoModelForCausalLM, AutoTokenizer
from trl import SFTConfig, SFTTrainer

from distill.modeling import MODEL_ID, pick_device


def to_prompt_completion(row):
    return {"prompt": row["messages"][:-1], "completion": row["messages"][-1:]}


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--output", default="outputs/lora-adapter")
    ap.add_argument("--max-steps", type=int, default=-1, help="cap steps (smoke test)")
    ap.add_argument("--device", help="mps or cpu (default: auto)")
    args = ap.parse_args()

    data = load_dataset("json", data_files={"train": "data/train.jsonl", "val": "data/val.jsonl"})
    data = data.map(to_prompt_completion, remove_columns=["messages"])

    tokenizer = AutoTokenizer.from_pretrained(MODEL_ID)
    model = AutoModelForCausalLM.from_pretrained(MODEL_ID, dtype=torch.float32)

    config = SFTConfig(
        output_dir=args.output,
        num_train_epochs=3,
        max_steps=args.max_steps,
        per_device_train_batch_size=4,
        per_device_eval_batch_size=4,
        gradient_accumulation_steps=4,
        learning_rate=2e-4,
        lr_scheduler_type="cosine",
        warmup_ratio=0.05,
        max_length=1024,
        completion_only_loss=True,
        eval_strategy="epoch",
        save_strategy="no",
        logging_steps=5,
        report_to="none",
        seed=42,
        use_cpu=pick_device(args.device) == "cpu",
    )
    lora = LoraConfig(
        r=16, lora_alpha=32, lora_dropout=0.05,
        target_modules="all-linear", task_type="CAUSAL_LM",
    )
    trainer = SFTTrainer(
        model=model,
        args=config,
        train_dataset=data["train"],
        eval_dataset=data["val"],
        processing_class=tokenizer,
        peft_config=lora,
    )
    trainer.train()
    print(trainer.evaluate())
    trainer.save_model(args.output)
    tokenizer.save_pretrained(args.output)
    print(f"saved adapter to {args.output}")


if __name__ == "__main__":
    main()
```
